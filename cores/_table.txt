# Cores whose whole recipe is a declaration: fetch from GitHub, build with the
# shared flags in _common.sh, verify, stage. A core needing anything more than
# this - a source patch, a build assertion, an .info fixup - gets its own
# cores/<name>.sh instead.
#
# Pipe-separated. Blank lines and #-comments are ignored. Trailing fields may be
# left empty.
#
#   name | owner/repo | make_dir | makefile | make args | extra CC/CXX defines
#
#   name        also names the .so and the .info (<name>_libretro.*)
#   make_dir    directory holding the libretro makefile, relative to the source
#               root; empty means the root itself
#   makefile    empty means Makefile
#
# Add a core by adding a row. Nothing else needs to change - build-core.sh and
# the release workflow both read this file.

# --- Nintendo ---------------------------------------------------------------
# Nestopia is more accurate than fceumm and heavier; both are kept so a game
# that misbehaves in one can be run in the other.
nestopia|libretro/nestopia|libretro|||
# Current Snes9x. snes9x2010 is the older, lighter fork of the same emulator.
snes9x|libretro/snes9x|libretro|||
# Without HAVE_STRTOF_L, mgba defines its own strtof_l and collides with the one
# libc.a already has in no-locale.o. With it, mgba calls a function the C headers
# never declare - hence the shim, which supplies the real prototype.
mgba|libretro/mgba||Makefile.libretro||-DHAVE_STRTOF_L -include ${ROOT_DIR}/shims/ps5-locale.h
